# Изменения LocalMind 1.0 — 28.10.2026

Ветка реализации поверх исходного checkout `5a140c6`. Обозначение 1.0 описывает
реализованный набор функций; аппаратная и визуальная приёмка перечислены отдельно
в STATUS/KNOWN_LIMITATIONS. Создание Git-коммитов ограничено правами среды.

## Выполнение и ответы

- Типизированный ActionResult отделяет действие, принятие запроса и наблюдение.
- После детерминированной фазы отдельный tool-free Ollama composer формирует
  комментарий; сбой или неверный JSON сохраняет правдивый fallback.
- Совместимый `/api/chat` и opt-in `/api/chat/stream` используют общий обработчик;
  статус отправляется до окончания генерации, action/LLM timings разделены.
- Ограниченное хранилище request_id защищает от гонок повторов в пределах сессии.
  Есть краткий/обычный/подробный ответ и отключение AI-комментария действий.

## Интерфейс

- Новый русский интерфейс с настройками, каталогом разрешений, статусами действий,
  отдельным техническим журналом и состояниями записи/обработки/ожидания/ошибки.
- Адаптивная компоновка, restrained CSS motion и prefers-reduced-motion.
- Расшифровка голоса остаётся одним редактируемым черновиком до отправки.
- Сохранены локальные Markdown/DOMPurify/KaTeX, шрифты и текстовый fallback;
  внешние медиа не загружаются, одинарные доллары — обычный текст.

## Голос и приложения

- Изолированный ограниченный voice worker, русские CPU/GPU профили, VAD,
  CPU fallback, явная предварительная загрузка ресурсов и `av==18.1.0`.
- Локальный Piper/Denis, WAV endpoint, start/stop/mute без браузерного cloud fallback.
- Каталог Start Menu/Desktop/App Paths, проверка локальных GUI executable,
  нормализованные псевдонимы, сессионные разрешения с отпечатком цели.
- Отказы для оболочек, скриптов, URL, аргументов и изменившихся целей.
  Безопасный отказ автозакрытия сохранён.

## Проверки и сопровождение

- Новые детерминированные тесты composer/dedup/catalog/voice/API и отрицательных
  сценариев; реальные границы декодирования проверяются PyAV.
- Дополнительные Host/Origin/body/proxy ограничения и secret-safe диагностика.
- Отдельные setup и offline startup, инструмент согласованного STT-измерения,
  объяснение архитектуры, 40 вопросов для защиты, протокол опытов и ограничения.
- Реальное качество STT/TTS, Windows-микрофон, GPU, HA, пять живых запусков
  приложений и визуальная приёмка не объявляются подтверждёнными mock-тестами.
