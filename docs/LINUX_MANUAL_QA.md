# Ручная приёмка LocalMind на CachyOS

Для приёмки используйте отдельный профиль и созданную вами тестовую папку.
В «Настройки → Доступ» выдавайте только операции, указанные в проверке.
При несовпадении записывайте текст запроса, фактический ответ и статус
в диагностике. Для физических проверок укажите модель устройства и ОС.

| Что сделать | Что должно произойти |
|---|---|
| Через Desktop спросить «Что такое RSA?» | Ответ на русском описывает открытый и закрытый ключ. В диагностике `ollama`, модель `gemma4:12b-it-q4_K_M`. Инструментов в ходе нет. |
| В той же беседе написать «Повтори предыдущий ответ», затем «Объясни проще» | В первом ходе повторяется смысл исходного ответа, во втором появляется более простое объяснение с опорой на историю. |
| Обновить каталог. Без разрешения написать «Открой Kitty». Затем выдать разрешения запуска и фокуса и повторить | Без разрешения отказ. При разрешении появляется процесс и, если Hyprland сопоставил окно с исполняемым файлом, отдельный факт о появлении окна. Если окно уже открыто, приложение выбирает существующее. |
| Запросить «Открой Steam», «Открой Стим», «Открой браузер» | Выбирается точная карточка каталога с выданным разрешением. Для браузера используется HTTPS-обработчик из XDG; при нескольких кандидатах нужен выбор. Появление окна Steam подтверждается отдельно от запуска wrapper. |
| Написать «Какие окна сейчас открыты?» и «Переключись на терминал» | Появляются проверенные окна приложений с разрешением. При одном окне терминала — фокус с подтверждением Hyprland. При нескольких — выбор конкретного окна. |
| Написать «Не открывай Kitty» и «Как открыть Kitty?» | Инструмент запуска не выполняется. |
| Попытаться закрыть документное окно | Приложение сообщает об ограничении безопасного закрытия. Содержимое и окна сохраняются. |
| В тестовой области создать `evidence.txt`. Дать поиск и чтение. Спросить «Какие файлы есть в папке „/абсолютная/папка“?» и «Прочитай файл „/абсолютная/папка/evidence.txt“» | Отображается фактический список и содержимое. В диагностике `files.list_directory` и `files.read_file` с результатом `observed`. |
| После чтения написать «Перескажи документ» | Gemma кратко пересказывает текст из выбранного файла. После отзыва разрешения новое чтение получает отказ. |
| Попросить удалить тестовый файл, сначала отменить, затем подготовить повторно и подтвердить | Отмена сохраняет файл. Одноразовое подтверждение удаляет точную цель. Если файл подменён до подтверждения, операция отклоняется. |
| Создать ссылку на тестовый файл из разрешённой папки и запросить чтение ссылки | Отказ. В ответе отсутствуют байты цели ссылки. |
| В настройках голоса нажать «Обновить список микрофонов», выбрать устройство и нажать запись | Список не начинает захват. После явного разрешения запись использует выбранный вход. Недоступный вход даёт ошибку без перехода на другой микрофон. |
| Сказать «Что такое алгоритм?», остановить запись и исправить текст до отправки | Расшифровка остаётся редактируемым черновиком. Ответ появляется только после отправки. При включённой озвучке слышен Silero xenia. |
| Повторить фразу с Medium и проверить диагностику | На доступной CUDA ожидается `cuda/float16`. При недоступной CUDA — CPU fallback с указанием устройства. |
| На подготовленном профиле отключить внешнее подключение и повторить предыдущие голосовые шаги | Ollama доступен через loopback. Расшифровка, ответ и озвучка проходят без загрузки. Демо-лампа явно помечена как симуляция. |
| Полностью выйти из Desktop и запустить его снова | История и явные разрешения сохранены. Выбранные окна и подтверждения предыдущего процесса больше не действуют. |
| В отдельном профиле установить пакет, запустить через меню, обновить, удалить и переустановить | Ярлык и иконка соответствуют пакету. После переустановки история и настройки сохранились. |
| В разблокированной сессии Secret Service подключить тестовый Home Assistant, перезапустить и отключить | Секрет восстанавливается через keyring. В конфигурации только ссылка на запись. После отключения тестовая запись удаляется. |

Для определения нагрузки Ollama используйте одновременно `ollama ps` и
`nvidia-smi --query-compute-apps=process_name,used_memory --format=csv`.
Для проверки защиты при записи используйте свою тестовую фразу. Автоматические
прогоны порта используют синтетический WAV и не читают микрофон.
На подготовленном DEMO-сервере автоматический прогон выполняется из корня
checkout командой `.venv/bin/python scripts/smoke_local.py --voice`.
Он добавляет один тестовый разговор. При другом порте укажите `--port`.
