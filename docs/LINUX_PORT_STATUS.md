# LocalMind Linux — результаты на CachyOS, 2026-11-22

Проверено на Hyprland / Wayland, Python 3.14.10, Ollama 0.40.16 и NVIDIA
RTX 4070 с драйвером 620.73.04. Windows-ветка релиза в работе не использовалась.
Порт прошёл приёмку основных сценариев из исходников. Установка системного
пакета и физическая микрофонная приёмка остаются открытыми.

## Модель и ресурсы

Выбран официальный `gemma4:12b-it-q4_K_M` в GGUF с Apache-2.0.
`/api/show` подтвердил 11.9B, Q4_K_M, llama.cpp, completion и tools.
`/api/tags` вернул размер 8 021 618 941 байт, digest
`6114515d63c17436a7c0417d82820ac65ad643e2806c5a3c89cb62846436ed0b`.
До подготовки проверены свободное место, RTX и официальная карточка.
Загружен один LLM-тег в изолированный каталог, Ollama проверил SHA-256 слоёв.
Точный тег применён как Linux default. Сохранённый выбор и `OLLAMA_MODEL`
имеют приоритет. Qwen3 8B остаётся альтернативой без автоматического выбора.
Каталог разрешает этот проверенный официальный вариант с Ollama 0.40.16.
Произвольный Gemma 4 GGUF с Hugging Face по-прежнему требует отдельной проверки.
[Официальная карточка Ollama](https://ollama.com/library/gemma4:12b-it-q4_K_M)

| Наблюдение | Результат |
|---|---|
| Локальная генерация Ollama | 62 токена, 96,51 токена/с на одном коротком ответе о RSA. Контекст 4096. |
| Фактическое размещение | `ollama ps` показал `100% GPU`. Замер NVIDIA — 8752 МиБ у llama-server, 10 069 МиБ занято на всём GPU в другом снимке того же сеанса. |
| API Ollama `size_vram` | 1 145 716 079 байт. Этот счётчик отличается от измерения всего runner через NVML. |
| Расчёт памяти | 7,47 ГиБ файлов модели, до 1,31 ГиБ FP16 KV при 4096 токенах без учёта сокращения sliding window, 1 ГиБ запаса runtime. Консервативная оценка полного размещения — около 9,78 ГиБ, осторожный CPU RAM бюджет — около 13,74 ГиБ. |
| Формат и инструменты | Реальная генерация по JSON Schema и native tool call с точным JSON-аргументом. В LocalMind команда Kitty прошла через `llm-tools` и проверенный адаптер. |

Совместное потребление Gemma и Whisper Medium может превысить доступную память
с активным рабочим столом. Для голосовой демонстрации с резидентной LLM
подходит Whisper Small / CPU. Результаты выше не являются нагрузочным тестом.

## Приложение и голос

- Нативный Wayland Desktop показал русский ответ Gemma в Qt WebEngine.
  В живом LocalMind API прошли RSA, повтор ответа и упрощение. Приложение
  прочитало разрешённый тестовый файл и передало в Gemma фактически извлечённый
  текст. Беседа и явное разрешение приложения пережили полный перезапуск.
- XDG-каталог обнаружил 29 поддерживаемых записей, включая Kitty, Steam и Zen
  Browser. Реальный запуск Kitty дал новый процесс и новое подтверждённое
  окно. Проверены список окон и фокус Kitty с подтверждением `activewindow`.
  «Открой браузер» выбрал системный Zen Browser и сфокусировал его открытое окно.
  «Открой Steam» создал процесс через штатный launcher. Тайм-аут наблюдения
  оставил `window_found=false`, так что появление окна Steam не подтверждено.
  Поддерживаются отдельные команды фокуса для Hyprland до 0.55 и начиная с 0.55.
- Документ читается через POSIX-дескриптор с проверкой идентичности. Запись и
  перемещение закрепляют проверенные родительские каталоги. Linux move
  использует атомарный rename без замены назначения. Сохраняются отдельное
  подтверждение и одноразовый срок действия.
- Whisper Small и Medium подготовлены через существующее HTTPS-зеркало с
  закреплёнными SHA-256. Размеры архивов 486 368 781 и 1 530 728 145 байт.
  Зафиксированы faster-whisper 1.2.1, CTranslate2 4.9.1 и PyAV 18.1.0.
- Silero xenia на Torch 2.15.0+cpu сгенерировал WAV 1,475 с. Первый TTS-вызов
  занял 2,48 с. Small CPU расшифровал «Что такое алгоритм?» за 1,46 с от
  приложения, включая старт worker и загрузку. Medium GPU вернул ту же фразу,
  329 мс inference, около 2092 МиБ VRAM worker после inference. При скрытой
  CUDA Medium вернул ту же фразу через CPU fallback, 1769 мс inference.
  Это одна синтетическая фраза в каждом режиме, без метрик качества микрофона.
- Через HTTP в отдельном Linux network namespace с одним loopback и без
  маршрута по умолчанию прошёл контур синтетический Silero WAV → Whisper →
  Gemma → Silero WAV 17,15 с. Во время прогрева TTS API может вернуть 429.
  Тест повторял запрос с ограничением до освобождения worker.
- PipeWire предоставил default input и output. `pw-play` завершил
  воспроизведение синтетического WAV с кодом 0. Физическую слышимость и запись с микрофона
  должен подтвердить человек. Автотест Chromium проверяет выбор точного
  аудиоустройства и ошибку недоступного входа.

## Тесты и границы этапа

- Python: 1734 passed, 31 skipped, 35 subtests passed. Пропуски включают
  Windows-native сценарии и недоступные ветви тестов. DOM, JavaScript и
  86 локальных ассетов проверены. Playwright Chromium: 37 passed.
- Первые таймауты двух браузерных тестов были ошибкой маршрутизации фикстуры:
  общий маршрут мешал подмене онбординга. После исправления порядок проверок
  сохранён. Смена IPC Hyprland и зависимость pytest от порядка моделей
  исправлены и покрыты тестами.
- Arch payload, desktop entry и иконка собраны и проверены через `makepkg --nodeps`,
  `pacman -Qlp` и `desktop-file-validate`. Установка,
  обновление и удаление через системный pacman требуют root-аутентификации.
  Системная установка на этой машине в этапе отсутствует.
- Не пройдены холодный запуск браузера, XWayland, слышимый TTS, микрофон,
  реальный Home Assistant и Windows mic/GPU. Запись, чтение и удаление
  одноразового фиктивного токена через LocalMind Secret Service проверены.
- Linux-адаптер поддерживает desktop entries без дополнительных аргументов, с обычными
  placeholders для файлов и URL, которые удаляются из запуска без входного
  файла. Flatpak/DBus-активация, автоматическое закрытие, минимизация,
  восстановление окон и внешнее открытие документов остаются отдельной работой.
- Первый запуск отдельного Ollama создал стандартную пару ключей
  `~/.ollama/id_ed25519` и `~/.ollama/id_ed25519.pub`, поскольку при явном
  `OLLAMA_MODELS` сохранился домашний каталог процесса. Ключи не читались и
  не удалялись. Повторный изолированный запуск использовал отдельный HOME.
  Ресурсы теста размещены в игнорируемом каталоге проекта.
