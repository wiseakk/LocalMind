# Инженерные задачи

| Задача | Решение | Что показывает проверка |
| --- | --- | --- |
| Перенос Windows → Linux | Общий API и UI, платформенные адаптеры для каталогов приложений, путей данных и окон. На Linux используются XDG и desktop entries. | Тесты путей и платформенных границ, реальный запуск Desktop на CachyOS. |
| Wayland и Hyprland | Qt WebEngine работает в Wayland-сеансе. Оконный адаптер выбирает поддерживаемый backend и сверяет активное окно после переключения фокуса. | Оконные операции проверялись на Hyprland. Покрытие других композиторов ограничено. |
| Локальная CUDA | Ollama загружает Gemma отдельно от Whisper. У ASR есть CPU-профиль и fallback при нехватке видеопамяти. | RTX 4070 использовалась для Gemma. Для одной фразы зафиксирован переход Medium на CPU при высокой загрузке VRAM. |
| Голос | Захват по кнопке, транскрибация в отдельном процессе, редактируемый текст перед отправкой, отдельный синтез и отмена озвучки. | Проверен полный маршрут с аудиофайлом в loopback-среде. Для WER/CER нужен набор размеченных записей. |
| Права доступа | Цель связывается с наблюдаемым каталогом или разрешённой областью. Перед выполнением проверяются политика и подтверждение. | Тесты разрешения и отказа для файлов и приложений. Смена разрешения проверяется при новом запросе. |
| Arch-пакет | `PKGBUILD` устанавливает код, launcher, desktop-file и голосовые библиотеки. Wheelhouse закреплён по хешам; модели готовятся отдельно. | Архив собран и запущен после извлечения. Полный цикл установки, обновления и удаления на чистой системе требует проверки. |
| TCP TIME_WAIT и EADDRINUSE | После остановки без LISTEN старый код не мог сделать повторный bind. POSIX использует `SO_REUSEADDR`, Windows сохраняет `SO_EXCLUSIVEADDRUSE`. | После исправления 20/20 повторных запусков на одном порту. Отдельно проверено сохранение чужого listener. |
| Жизненный цикл сервера | При закрытии Uvicorn получает сигнал остановки. Desktop ждёт поток и закрывает сокет в `finally`, в том числе при отказах запуска. | Проверены отказ ASGI, отказ Qt и диагностика без полного текста исключения. |
