Публичная отправка остановлена. Эта запись описывает типы находок без значений credentials, имён локальных профилей и адресов инфраструктуры.

## Git и данные

- Gitleaks 8.24.3 с `git --log-opts='--all --full-history -m' --redact=100` проверил 51 коммит Linux refs, 41 коммит Windows RC3 и 26 коммитов раннего Windows MVP. Совпадений правил поиска секретов не обнаружено.
- Отдельная проверка Git обнаружила локальные пути профилей в документах и журналах испытаний, авторский email вне GitHub noreply и привязку конфигурации ASR к стороннему зеркалу. Данные встречаются в достижимых коммитах. Текущая ветка маскирует известные пути и отключает зеркало. Для публичного использования полной исходной истории нужно отдельно подтвердить разрешение на раскрытие найденных метаданных. Изменения текущего дерева не очищают предыдущие коммиты.
- По именам и размерам Git-объектов проверены модели, базы, записи, архивы, ключи, логи и `.env`. `.env.example` содержит примеры. Исторические диагностические данные в `docs/evidence` требуют ручной оценки перед раскрытием.
- Windows RC3 и Linux сходятся в `0615b9e`. Ветки RC3 остались в исходной копии и как локальные tracking refs, архивные ветки MVP сохранены в `refs/archive/windows-mvp/heads/*`, его тег сохранён в `refs/archive/windows-mvp/tags/*`. Исходная история сохранена.
- GitHub-коннектор подтвердил владельца `wiseakk`. Запрос `wiseakk/LocalMind` вернул 404. Установка `gh` в каталог инструментов проекта подтвердила отсутствие локальной авторизации. Возможность создания репозитория в коннекторе отсутствует.

## Релизные файлы

Linux-пакет локальный, без подписи и установочных скриптов. SHA-256 совпал с протоколом. Проверены список файлов, безопасные имена путей архива и соответствие исходников, см. [протокол](DEVELOPMENT_EVIDENCE.md). Архив включает PyTorch test fixture и библиотеки голосового runtime. Моделей Ollama, рабочих весов Whisper/Silero и пользовательского профиля в списке содержимого нет. Для передачи архива требуется отдельное подтверждение условий распространения его runtime.

У Windows RC3 найдены пять версий Setup и соответствующие архивы. Для bug-bash сборки проверены локальные SHA-256, заявленный Git commit и побайтовое соответствие файлов source ZIP после нормализации CRLF. Стадия сборки содержит упакованные Python-компоненты и Ollama. Совпадение локального хеша устанавливает целостность, для публичной поставки остаются проверка вложенного установщика и лицензий. Windows-бинарники не запускались.
