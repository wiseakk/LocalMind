# Подготовка публичной истории

В отдельной копии Git личный email владельца заменён на GitHub noreply.
Локальные пути профиля обезличены, адрес стороннего зеркала удалён.
Имена авторов, даты и порядок разработки сохранены. У исходного
репозитория и этой копии разные идентификаторы затронутых коммитов.

Публичная поставка включает код Linux Alpha, историю Windows RC3,
документацию и скриншоты из демонстрационного профиля. В архив исходников
входят уведомления Marked, DOMPurify, KaTeX и шрифтов. Собственный код
опубликован по MIT с разрешения владельца.

Закреплённые версии, модельные веса и библиотеки можно подготовить по
инструкциям установки. Собранные Arch-пакет и Windows Setup остаются
локальными до проверки условий распространения встроенных библиотек.
