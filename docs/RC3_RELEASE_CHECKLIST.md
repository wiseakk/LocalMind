# LocalMind RC3. Приёмка перед демо и выпуском

Запуск из подготовленного проектного venv: `python -m localmind.desktop`.
Для демонстрации без сети заранее подготовьте Gemma, Whisper Small и Silero.
Загрузка моделей требует сети или проверенного локального импорта. Все
файловые изменения выполняйте только в специально созданной папке QA.
Отдельно фиксируйте Windows, commit из `build-provenance.json`, модели,
масштаб окна и наблюдения. Считайте действие подтверждённым по диагностике
и фактическому состоянию Windows.

## Перед записью демо

- [ ] Запустите окно с чистым QA-профилем. Должно появиться «Добро пожаловать».
  Проверьте «Далее», «Назад», «Настроить позже», Escape, закрытие окна и
  повторный запуск. Убедитесь, что встроенный Ollama не предлагает отдельную
  установку и существующая Gemma доступна без скачивания.
- [ ] Спросите «Как работает RSA-шифрование?» и «Объясни предыдущий ответ проще».
  В диагностике виден ответ выбранной локальной модели без действий. После
  перезапуска обе реплики открываются из истории. Создайте новый чат и
  сразу введите фразу, как только поле станет доступно. Ввод должен сохраниться.
- [ ] В ограниченном режиме разрешите «Поиск» и «Чтение» для тестовой папки
  с пробелами. Выполните `Какие файлы есть в папке «C:\…\Папка QA»?`.
  Сверьте имена с `Get-ChildItem -LiteralPath 'C:\…\Папка QA' -Force`.
  Диагностика показывает `files.list_directory`, `observed`, `llm_ms=0`.
- [ ] Отправьте `Прочитай файл «C:\…\Папка QA\Русский файл.txt»`, затем
  `О чём файл «C:\…\Папка QA\Русский файл.txt»?`. Сверьте прямой ответ с
  содержимым. Пересказ должен опираться на `files.read_file` / `text_extracted`.
  Повторите без разрешения и убедитесь, что данные не показаны.
- [ ] В разрешённой тестовой области запустите `Найди последний скачанный PDF в Загрузках`.
  Сверьте кандидата и время последнего изменения. При поиске без разрешения
  или в пустой области приложение должно объяснить отсутствие результата.
- [ ] В полном режиме явно разрешите удаление только тестового файла.
  `Удали файл «C:\…\Папка QA\одноразовый.txt»` открывает подтверждение.
  «Отмена» оставляет файл. Новый запрос и «Подтвердить» удаляют ровно этот
  файл. Двойное нажатие и повтор подтверждения не выполняют вторую операцию.
- [ ] Скажите «Открой калькулятор», «Какие окна сейчас открыты?» и
  «Переключись на калькулятор». Сверьте реальное окно, а не только PID.
  При двух окнах выберите конкретное. Отдельно проверьте отказ для
  отсутствующего приложения и запрет закрытия. Используйте только тестовые окна.
- [ ] Включите, повторно включите и выключите DEMO-лампу. Вопрос «Лампа сейчас
  включена?» должен показать наблюдаемое состояние и пометку DEMO.
- [ ] Откройте «Возможности» при 100%, 125%, 150% и 175%. В минимальном и
  развёрнутом окне прокрутите до правил. Кнопка закрытия остаётся видимой и
  кликабельной. Escape закрывает окно, фокус возвращается к кнопке открытия.
- [ ] Запишите с физического микрофона «Как сварить пельмени?» и «Открой
  калькулятор». Сверьте черновик до отправки. Проверьте mute, возобновление
  и остановку TTS. Повторите с заранее подготовленными моделями при отключённом
  интернете. Отдельно запишите результат GPU и CPU fallback.

## Ворота установщика

- [ ] Проверить чистые Windows 10/11 без глобального Ollama и без моделей.
  После первого запуска выбрать и загрузить модель из UI, дождаться
  пробной генерации и получить первый ответ без командной строки.
- [ ] Проверить Windows с существующими Gemma/Whisper. Ни одна установленная
  модель не скачивается и не копируется повторно. Закрытие LocalMind не
  останавливает общий Ollama.
- [ ] Проверить запуск без интернета и недоступную выбранную модель.
  Встроенный движок готов, отсутствующая модель отмечена честно. При занятом
  порте и при сбое собственного Ollama проверяются уведомление и «Повторить».
- [ ] Проверить обрыв загрузки в безопасном тестовом сценарии. Показаны
  ошибка и доступный повтор. HTTPS-зеркало предлагается после ошибки HF,
  загружается только по согласию, докачивает проверяемый остаток и проверяет SHA.
- [ ] Проверить физический микрофон, GPU/CPU, журнал ошибок, повторный запуск
  после перезагрузки Windows и отсутствие роста числа фоновых процессов.
- [ ] После ручной приёмки повторить `python -m pytest -q`, `npm run test:dom`,
  `npm run check:ui` и `npm run test:ui` на изолированном FastAPI-профиле.
  Записать SHA утверждённого коммита и только затем переходить к выпуску.

Если не работает пересказ, сначала проверьте модель в разделе «Модели» и
наличие `text_extracted`. Если список папки отклонён, проверьте именно
разрешение «Поиск» и явные запреты. При ошибке голосового ввода проверьте
состояние Whisper и разрешение микрофона. Вопросы и ответы для защиты
собраны в [DEFENSE_QA](DEFENSE_QA.md).
