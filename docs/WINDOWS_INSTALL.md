# Windows 10/11 · RC3

Используйте [ветку Windows RC3](https://github.com/wiseakk/LocalMind/tree/release/1.0.0-rc3).
В PowerShell из каталога исходников установите зависимости через
`.\setup_windows.ps1`. Для базовых голосовых зависимостей используйте
`.\setup_windows.ps1 -Voice`. Требуется Python с командой `py`.

Установите Ollama, подготовьте совместимую локальную модель и проверьте
`ollama list`. Запустите `.\start_windows.ps1` и откройте
`http://127.0.0.1:8765`. Модели можно выбрать и проверить в интерфейсе.
Whisper и Silero требуют отдельной подготовки.

Актуальный публичный EXE отсутствует. Для полной приёмки на Windows см.
[чек-лист](../MANUAL_QA.md). Об ошибках запуска, озвучки или порта см.
[ручную диагностику](../MANUAL_QA.md#troubleshooting).
