# Ограничения LocalMind 1.0

Этот документ объясняет границы реализации, а не подтверждает готовность
аппаратного продукта. Актуальные результаты проверки — в `STATUS.md`.

- **Аппаратный голос не подтверждён.** Нет записи реального Windows-микрофона,
  WER/CER человеческой речи, GPU inference или прослушивания TTS. PyAV реально
  декодировался. Отдельно проверены реальные CPU base/small и Piper1.8/Denis на
  одном synthetic WAV; обе модели ошиблись. Результаты в EXPERIMENTS. Модели
  загружены в `models`, Piper распакован только в `.voice-deps` для smoke;
  обычному окружению нужны зависимости или явный PYTHONPATH. Setup — в `VOICE.md`.
- **Voice API ограничен sandbox ACL.** Private TemporaryDirectory Python3.14
  в restricted-token среде исключает SID sandbox. Приложение сообщает safe503
  без путей; production ACL не ослаблена. Реальные движки вызывались напрямую
  в проектном scratch на synthetic audio. Это не подтверждает нормальный HTTP
  voice путь: его необходимо проверить в обычной пользовательской Windows-сессии.
- **CPU по умолчанию.** GPU-профиль не доказывает наличие CUDA. Fallback сообщает
  переход на CPU, но medium может не уложиться в 120 секунд на слабом ПК.
  Ollama и STT делят VRAM. Автоматической установки CUDA-библиотек нет.
- **Один голосовой worker.** STT и TTS сериализованы; параллельная операция
  получает 429. Загрузка модели на каждый запрос увеличивает задержку, зато
  зависший native процесс можно остановить и освободить память.
- **Лимиты.** Запись до 30 сек/8 МБ, TTS до 1200 символов/2 минут/12 МБ,
  весь voice worker до 120 сек. Длинные диктовки и аудиофайлы здесь не поддерживаются.
- **Нет жёсткого лимита native RAM.** Размер загрузки, время и число workers
  ограничены, но проверка числа samples происходит после выделения кадра FFmpeg.
  Это не доказывает ограничение пиковой памяти на повреждённом медиа. Конкретный
  OOM на таком файле не воспроизведён. Перед расширением доверенной локальной
  границы нужен отдельно проверенный Windows Job Object commit-limit worker;
  здесь он не реализован. Не следует трактовать timeout как RAM sandbox.
- **Каталог не универсальный установщик.** Поддержаны обнаруженные локальные
  GUI `.exe` из ограниченного набора имён, без аргументов. UWP/MSIX со специальной
  активацией, URL-ярлыки, CLI и обёртки Update.exe не поддерживаются. Поэтому даже
  установленный Codex/Discord может не попасть в каталог. Необходимое число
  реальных приложений нельзя утверждать по тестовым fixtures.
- **Разрешения сессионные.** После перезапуска их нужно выдать снова. Обновление
  executable или ярлыка меняет отпечаток и отменяет допуск. PE-проверка и хеш
  не заменяют доверие пользователя к установленной программе или антивирус.
- **Автозакрытие запрещено.** Нет надёжного владения конкретным окном и проверки
  несохранённых данных. Окна закрываются вручную штатными средствами Windows.
- **Дедупликация ограничена процессом и временем.** Записи хранятся пять минут
  после завершения; максимум 128 ID и четыре одновременно выполняемых chat-запроса.
  Неистёкшие записи не вытесняются. Совпадающий ID помогает только в этой сессии
  и с тем же содержимым. После crash/restart/TTL автоматический повтор может
  выполнить действие заново; сначала проверьте фактическое состояние вручную.
- **Модель может ошибаться.** Проверки composer отбрасывают несовпадения JSON и
  некоторые ложные формулировки, но не доказывают смысл произвольного текста.
  Детерминированный статус имеет приоритет. Образовательные ответы также требуют
  проверки по учебным источникам; показанный текст не является сертификатом точности.
- **Нет наблюдения окна/лампы после внешней команды.** Создание процесса и
  принятие HA-запроса явно отделены от подтверждённого состояния. Home Assistant
  не проверялся на реальном оборудовании в этом прогоне. По умолчанию — DEMO.
- **Только этот компьютер.** Сервер привязан к loopback, LAN и телефон как
  спутник не реализованы. Нет защищённого сопряжения, аккаунтов, HTTPS-публикации,
  wake word, постоянного прослушивания или готовой физической колонки.
- **Нет постоянной истории.** Диалог и настройки вкладки в памяти, права
  приложений на сервере в памяти. Закрытие/перезапуск сбрасывает их. Ключ не
  сохраняется в localStorage; временное аудио удаляется после обработки.
- **Браузерная проверка ограничена средой.** CUA не предоставил браузер;
  установка Playwright-браузера остановилась с EPERM. Реальное воспроизведение,
  keyboard, reduced motion и zoom 100/125/140% требуют отдельного прогона.
  Статические тесты не заменяют визуальную приёмку.
- **Коммиты в этом worktree заблокированы.** Общие Git-метаданные лежат вне
  разрешённого для записи корня. Изменения остаются проверяемым diff; push/merge
  не выполнялись. Это ограничение среды, а не повод заявлять несуществующий commit.

Для чистой аппаратной приёмки: подготовьте зависимости и модели, выполните
offline-сценарий из README, проверьте реальные программы/микрофон/Piper/GPU/HA
отдельными пунктами и запишите наблюдения. Недоступное устройство помечается
«не проверено», а не «работает по результатам mock».
