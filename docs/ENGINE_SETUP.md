# Встроенный AI-движок LocalMind RC3

Пользователь запускает Setup.exe и затем LocalMind. Отдельная установка Ollama,
PATH, PowerShell, служба Windows и права администратора не требуются. В мастере
«Нейросеть» нужно выбрать модель, принять её лицензию и нажать загрузку. Прогресс,
отмена и повтор доступны там же и в «Загрузках». После скачивания выполняется
короткая настоящая генерация. «Проверить и использовать» активирует модель только
после успешного ответа и сохраняет выбор вместе с digest. Удалённая или изменённая
модель перестаёт считаться проверенной; скрыто повторно не скачивается.

## Уже установленные модели Ollama

Перед запуском собственного движка LocalMind проверяет `OLLAMA_MODELS` текущего
процесса и пользовательскую настройку Windows, `%USERPROFILE%\.ollama\models`,
собственный `models/llm` и прежний каталог `models`. Найденное хранилище показывается
на этапе «Нейросеть»: нажмите «Использовать эти модели», затем «Проверить и
использовать gemma4:12b» (или другую модель). Это не загрузка и не копирование.
Проверяются manifests, наличие/размер blobs и заголовок GGUF; окончательная
совместимость определяется API Ollama и реальным ответом, а не одним именем файла.
Первый запуск большой модели с GPU-прогревом может занять до трёх минут.

Выбор каталога сохраняется отдельно от модели с identity каталога. Собственный
дочерний Ollama получает абсолютный `OLLAMA_MODELS` и `OLLAMA_NOPRUNE=1`; глобальные
переменные пользователя не меняются. NOPRUNE отключает очистку blobs при старте
([upstream envconfig](https://raw.githubusercontent.com/ollama/ollama/v0.40.14/envconfig/config.go)).
Веса не перемещаются, не переписываются и не удаляются. При исчезновении выбранного
каталога требуется новый явный выбор; отсутствующая сохранённая модель не считается
доступной. Для чистой установки остаётся мастер явной загрузки.

Уже работающий совместимый локальный сервер имеет приоритет: второго экземпляра
не создаётся, его каталог/окружение не меняются. Если такой сервер показывает пустой
список, LocalMind честно показывает пустой список; он не выдаёт найденные на диске
модели за доступные этому серверу и не останавливает чужой процесс ради смены каталога.

## Интернет, диск и оборудование

Windows x64, Windows 10 22H2 или Windows 11. Для NVIDIA официальный минимум
драйвера — 551.61; LocalMind драйверы не устанавливает. Без рабочего GPU возможен
CPU-режим, скорость зависит от процессора. Мастер показывает фактически полученные
сведения CPU/RAM/GPU; отсутствие телеметрии не является тестом отсутствия GPU.

Standalone занимает около 2,25 ГБ распакованным плюс Python/Qt/голосовые библиотеки.
Практический резерв: 10 ГиБ для приложения/временных файлов и отдельно место под
выбранную модель с запасом. В карточке проверяется свободное место именно для
хранилища работающего Ollama: минимум размер модели × 1,1 + 1 ГиБ. Маленькая
Qwen2.5 0.5B (~398 МБ) — диагностика/CPU, качество не эквивалентно Qwen3 4B
(~2,6 ГБ) или 8B (~5,2 ГБ). Потребление RAM/VRAM в карточках — оценка, а не
benchmark или гарантия полного GPU-размещения.

Интернет нужен для первого скачивания выбранной модели, повторной/возобновлённой
загрузки и получения новых моделей. После успешной проверки установленной модели
локальный чат работает без интернета. Встроенный движок стартует без интернета
и без модели, но отвечать без весов не может. Голосовые модели — отдельный явный
выбор мастера. Отмена закрывает принадлежащий задаче поток; остановка pull внутри
общего Ollama не выдается за доказанный факт. Повтор использует сохранённые слои
Ollama; автоматического скрытого скачивания после перезагрузки нет.

## Жизненный цикл и восстановление

Старт идёт в фоне: version/tags существующего локального API → reuse, иначе при
свободном порте запускается только абсолютный bundled ollama.exe serve. Собственный
процесс получает loopback 127.0.0.1, OLLAMA_NO_CLOUD=1 и выбранное постоянное
хранилище (по умолчанию LocalMind при чистой установке). Он и его runner находятся в Windows Job Object. При выходе
закрывается только этот job, а общий Ollama не завершается. При аварии собственного
процесса разрешены две автоматические попытки восстановления, затем нужна кнопка
«Повторить запуск движка». Бесконечного цикла нет.

Если порт занят не-Ollama/несовместимым сервисом, приложение его не останавливает
и не открывает наружу другой порт. Освободите выбранный локальный порт и нажмите
«Повторить». Если runtime изменён/неполон, восстановите приложение Setup.exe.
Если модель отсутствует, выберите её загрузку явно. При сбое сети повторите задачу
в «Загрузках»; оставшиеся слои не удаляются. При недостатке диска откройте настройки
хранилища в приложении; данные не перемещаются без отдельного согласия.

Запуск исходников после подготовки зависимостей: `python start.py`. Для офлайн-демо
сначала завершить скачивание/проверку, затем повторно открыть приложение и задать
короткий вопрос. Полная защита проекта: `docs/DEFENSE_QA.md` (60+ вопросов/ответов).

## Фактическая приёмка

Discovery-проверка: собственный v0.40.14 на 11543 видит существующие модели из
стандартного пользовательского каталога, Gemma 12B отвечает «Четыре.» и «Привет»
после рестарта. Затем финальный payload установлен отдельным QA Setup в workspace
(отдельный AppId, без ярлыков/uninstall registry). SHA256 19855 файлов совпал.
Установленный мастер (JSDOM-shell, настоящий HTTP/Ollama) выполнил выбор каталога
и модели без pull. Настоящий /api/chat ответил «Два плюс два равно четыре.»,
actual_model=gemma4:12b. После перезапуска приложения выбор и verified digest
сохранились. Размеры/mtime blobs и SHA256 manifests не изменились. Отчёты:
`.test-artifacts/existing-models-report.json`, `installed-models-report.json`.
Это не проверка native-кликов/ярлыков, но inference и установленный backend настоящие.

Реальный v0.40.14 запущен в отдельной тестовой папке/порту 11540, не через PATH.
Пустые tags, reuse вторым клиентом без второго процесса, скачивание 398 МБ,
проверка ответа, сохранение выбора/digest, восстановление собственного PID,
GPU-размещение (/api/ps size_vram==size) и принудительный CPU (size_vram==0)
проверены настоящим бинарным движком. Примеры ответов: «Ответ: четыре» и «Привет».
Данные: `.test-artifacts/real-engine-first-pull-report.json`,
`.test-artifacts/real-engine-report.json`. Это не mock Ollama.

Чистая Windows 10/11 и физическая машина без GPU: НЕ ПРОВЕРЕНЫ. Владелец сообщил,
что VM нет, и согласовал подготовку сборки с явным указанием этого ограничения.
Наличие глобального Ollama на тестовом ПК не скрывается. Установщик и GUI имеют
отдельный протокол в STATUS; одни unit-тесты не закрывают критерий готовности.
