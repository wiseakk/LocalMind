# Whisper Small и Medium на Windows

Откройте «Микрофон и распознавание» в мастере или «Настройки → Голос и микрофон».
Профили `cpu-fast` и `balanced` используют Small, `gpu-quality` использует Medium.
Нажмите «Скачать Whisper», чтобы проверить рабочий каталог модели и при необходимости
загрузить закреплённую версию Systran с Hugging Face. Если файлы уже присутствуют,
LocalMind проверит их на месте. После сетевой ошибки карточка загрузки предложит
Яндекс Диск, если для выбранной модели задано зеркало. Скачивание с зеркала
начинается по отдельной кнопке.

Без сети выберите «Импортировать из файла» для ZIP или «Импортировать из папки»
для каталога. Браузер передаёт приложению выбранные байты через локальный API.
LocalMind проверяет четыре файла по размерам и SHA‑256 из
`config/voice_resources.json`. Для ZIP с зеркала дополнительно проверяется SHA‑256
всего архива до распаковки. На этапе «Проверяем модель» приложение загружает
CTranslate2 через `faster-whisper` в режиме CPU и выполняет короткую пробу.
Текстовый чат остаётся доступен, пока голосовые модели отсутствуют или готовятся.

## Подготовка архива

Используйте опубликованные Systran версии [Small](https://huggingface.co/Systran/faster-whisper-small)
и [Medium](https://huggingface.co/Systran/faster-whisper-medium) из манифеста.
Карточки моделей указывают MIT. При публикации приложите сведения об источнике
и лицензии рядом с архивом. В ZIP положите `config.json`, `model.bin`,
`tokenizer.json` и `vocabulary.txt` в корень либо в одну папку `small/` или
`medium/`. Поддерживаются обычные ZIP без шифрования, с STORE или DEFLATE.

Пример подготовки в PowerShell из корня репозитория на компьютере, где доступен
Hugging Face. Используйте новую папку для каждой публикации.

```powershell
$releaseDir = New-Item -ItemType Directory -Path '.test-artifacts/whisper-mirror-export'
$manifest = Get-Content -Raw -Encoding UTF8 config/voice_resources.json | ConvertFrom-Json
foreach ($model in @('small', 'medium')) {
    $modelDir = New-Item -ItemType Directory -Path (Join-Path $releaseDir.FullName $model)
    $files = foreach ($asset in $manifest.assets | Where-Object path -like "whisper/$model/*") {
        $file = Join-Path $modelDir.FullName (Split-Path $asset.path -Leaf)
        Invoke-WebRequest -Uri $asset.url -OutFile $file
        if ((Get-Item -LiteralPath $file).Length -ne $asset.bytes -or
            (Get-FileHash -LiteralPath $file -Algorithm SHA256).Hash.ToLowerInvariant() -ne $asset.sha256) {
            throw "Проверка файла не пройдена: $file"
        }
        $file
    }
    $zip = Join-Path $releaseDir.FullName "whisper-$model.zip"
    Compress-Archive -LiteralPath $files -DestinationPath $zip
    Get-FileHash -LiteralPath $zip -Algorithm SHA256
    Get-Item -LiteralPath $zip | Select-Object Name, Length
}
```

Загрузите каждый готовый ZIP на Яндекс Диск. Включите доступ по ссылке для файла
и проверьте, что в ссылке разрешено скачивание. В `config/asr_mirrors.json`
замените `null` только у опубликованных моделей. Пример структуры с заполнителями:

```json
{
  "small": {
    "url": "<публичная HTTPS-ссылка на whisper-small.zip>",
    "sha256": "<64 шестнадцатеричных символа SHA-256 готового ZIP>"
  },
  "medium": null
}
```

Поле `bytes` принимает точный размер ZIP в байтах и позволяет показать его до
скачивания. Для Medium заполните отдельную запись по той же схеме. В репозитории
обе записи оставлены `null`, пока нет опубликованных архивов и их хешей.
LocalMind передаёт публичную ссылку в API Яндекс Диска как `public_key` и скачивает
по выданной HTTPS-ссылке. [Документация Яндекса](https://yandex.cloud/ru-kz/docs/datasphere/operations/data/connect-to-ya-disk)

## Ручная проверка без VPN

1. Запустите LocalMind с новым тестовым профилем. Ожидается «Добро пожаловать».
   Нажмите «Далее» и выберите Small. Для Medium повторите тест в профиле
   «Качественный». На карточке должны быть видны модель, размер и источник.
2. Скачайте Small на машине, где доступен Hugging Face. Дождитесь «Проверяем
   модель», затем «Готово». Перезапустите приложение. Готовая модель определяется
   локально, повторная загрузка не требуется.
3. В отдельном новом профиле, без VPN и в сети, где Hugging Face недоступен,
   нажмите «Скачать Whisper». После ошибки появится кнопка Яндекс Диска
   только при настроенном зеркале. До явного нажатия второй загрузки нет.
4. Начните скачивание с Яндекс Диска. Дождитесь ненулевого прогресса и скорости,
   нажмите «Отменить» и дождитесь подтверждения. Карточка модели не должна
   перейти в «Готово». Нажмите «Повторить». Архив скачивается с начала.
5. При недоступности обоих источников проверьте сообщение об ошибке.
   Импортируйте заранее проверенный ZIP в одном чистом профиле, затем папку
   модели в другом. Повреждённый ZIP, неправильная модель и ошибка контрольной
   суммы должны завершиться ошибкой до публикации.
6. После установки отключите интернет и перезапустите приложение. Продиктуйте
   фразы ниже. Проверяйте расшифровку в поле ввода до отправки.

| Фраза | Что проверить |
| --- | --- |
| «Я готовлю пельмени» | Сохранены слова «готовлю пельмени» |
| «Поставь таймер на пять минут» | Распознаны «таймер» и «пять» или «5 минут» |
| «Не открывай калькулятор» | Сохранено отрицание «не» |
| «Расскажи, как работает шифрование» | Сохранены вопрос и слово «шифрование» |

Если модель не определяется, сравните четыре файла с манифестом и проверьте
выбранный профиль. При нехватке места учитывайте размер архива и распакованной
модели одновременно. При ошибке Яндекс Диска проверьте публичность ссылки,
доступность скачивания, лимит сервиса и SHA‑256. Предыдущий каталог при замене
сохраняется как `small.previous-…` или `medium.previous-…`. Эти папки не участвуют
в распознавании.

Запуск из подготовленного окружения: `python start.py`. Для офлайн-демо
подготовьте ASR и локальную модель Ollama, перезапустите LocalMind без сети,
проверьте расшифровку и отправьте обычный вопрос. [Разбор на защите](DEFENSE_QA.md)
