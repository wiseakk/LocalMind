# Linux rc3-3 — исправление блокера загрузок

## Воспроизведение на установленном rc3-2

Установленная версия `localmind 1.0.0rc3-2` запускала системный
`/usr/bin/python` из `/usr/lib/localmind`. Для запроса использован отдельный
чистый XDG-профиль и системный Ollama 0.40.16 на `127.0.0.1:11434`.
Приложение видело Ollama, но список моделей сервиса был пуст.

| Запрос установленного приложения | Ответ и причина |
|---|---|
| `POST /api/models/downloads` для Gemma по умолчанию | HTTP 409, «Активная модель не перезаписывается». Сохранённое имя трактовалось как доказательство установленной модели. |
| `POST /api/models/downloads` для резервной LLM | HTTP 409, «Свободное место неизвестно». Обычный экран скрывал подтверждение, а мастер его не отправлял. |
| `POST /api/setup/voice`, `kind=asr` | HTTP 409. В системном Python отсутствовали faster-whisper, PyAV, CTranslate2 и NumPy. |
| `POST /api/setup/voice`, `kind=tts` | HTTP 409. В системном Python отсутствовали Torch и NumPy. |
| `GET /api/downloads` после отказов | HTTP 200, `jobs: []`. Ни один worker не получил задачу. |

Наблюдение сохранено в `.test-artifacts/rc3-2-installed-downloads.log`.
В проектном venv голосовые библиотеки были установлены, а тестовый Ollama
работал от того же пользователя, поэтому его каталог поддавался проверке.
На обычной установке служба Ollama владеет `/var/lib/ollama`. LocalMind передаёт
загрузки в `/api/pull`, а недоступность информации о диске показывается в UI
с отдельным явным подтверждением. Системный сервис и его конфигурация сохранены.

## Что входит в rc3-3

Пакет содержит runtime Python 3.14 x86_64 под `/usr/lib/localmind/voice-runtime`
и использует системный Python/Qt. Комплект включает faster-whisper 1.2.1,
PyAV 18.1.0, CTranslate2 4.9.1, Torch 2.15.0+cpu и библиотеки CUDA 12/cuDNN 9
для ASR. Wheel закреплены версиями и SHA-256. Сборка использует локальный
wheelhouse, запуск работает без проектного venv или установки через pip.
Скачанные голосовые веса и журнал остаются под `$XDG_DATA_HOME/LocalMind`
или `~/.local/share/LocalMind`. `/usr` содержит только файлы пакета.

Защита от перезаписи активной установленной LLM действует после проверки
фактических tags. Выбор выполняется после реальной генерации. Загрузки LLM
показывают события Ollama, повтор использует хранилище daemon. Whisper
сохраняет существующие источники Hugging Face, закреплённые HTTPS-зеркала и
локальный импорт. Механизм проверки SHA-256, ETag, Range и архивов сохранён.
Ошибки различают недоступную сеть, отсутствующую библиотеку, права, место
и несовпадение контрольной суммы.

## Свидетельства и границы приёмки

В живом Chromium, без моков API, системный Python обслуживал staged payload
пакета с чистым XDG. Тестовый Ollama работал в отдельном хранилище. Кнопки
мастера начали реальные задачи:

- Qwen2.5 0.5B Q4_K_M, 397 821 319 байт. Ollama скачал модель, LocalMind выполнил
  проверочную генерацию, пользовательское действие выбрало модель.
- Whisper Small. Существующие большие файлы использованы как тестовые
  копии. Hugging Face доставил отсутствующий `config.json`. Суммарный
  проверенный ресурс — 486 212 372 байт. CPU распознал синтетический текст.
- Whisper Medium. Подготовлены повторно использованные файлы, 1 530 571 735 байт.
  Проверка и реальное распознавание на CUDA прошли без повторного скачивания.
- Silero xenia. Реально скачано и проверено 147 664 410 байт. Движок
  сгенерировал WAV на 70 844 байта, `pw-play` завершился с кодом 0.
- Выбранная LLM и голосовые ресурсы сохранились после перезапуска.

Логи живого UI и backend находятся в `.test-artifacts/rc3-3-live-ui.log`
и `.test-artifacts/rc3-3-ui-processes.log`. Gemma и Medium повторно не скачивались.
Python-регрессии: **1740 passed, 31 skipped, 35 subtests passed**.
Проверки синтаксиса JS и DOM прошли. Chromium против извлечённого финального
архива: **37 passed**. Qt Wayland запустился из этого архива через системный
Python и показал состояние обычного Ollama. В отдельном namespace без
внешней сети ASR показал отказ Hugging Face и предложил зеркало. Отмена,
повтор подготовки и реальный CPU fallback Medium при скрытой CUDA прошли.

SHA-256 финального архива:

`0818c977d85c1599765589aebeac4e4016bbd794018fa83b766552277eb389d2`.
Размер после установки по pacman — 3291,60 МиБ. Установочных скриптов нет.

**Системная приёмка rc3-3 открыта.** `sudo -n -l` требует пароль.
Установленная версия на машине остаётся rc3-2. Тесты payload и архива
не заменяют обновление через pacman и запуск установленного ярлыка.

## Обновление и ручная проверка

```sh
sudo pacman -U .test-artifacts/rc3-3-release/localmind-1.0.0rc3-3-x86_64.pkg.tar.zst
pacman -Q localmind
gtk-launch localmind
```

Для проверки без изменений обычного профиля после установки:

```sh
XDG_DATA_HOME="$(mktemp -d)" gtk-launch localmind
```

1. В мастере «Нейросеть» проверьте системный Ollama. Выберите небольшую
   модель, явно примите лицензию и подтвердите загрузку при неизвестном
   свободном месте. Проверьте прогресс. После завершения нажмите
   «Проверить и использовать», затем отправьте короткий текстовый вопрос.
2. В мастере нажмите «Скачать Whisper» и «Подготовить озвучку». Дождитесь
   готовности. Для недоступного Hugging Face проверьте предложение уже
   настроенного зеркала или импорт. Повторите подготовку существующего
   ресурса и проверьте, что файлы не скачиваются повторно.
3. Выберите физический микрофон, запишите короткую фразу на русском, проверьте
   редактируемую расшифровку и слышимый Silero. Перезапустите приложение,
   проверьте историю, выбранную модель, ресурсы и отсутствие ручного venv.
4. На тестовой задаче нажмите отмену и откройте «Загрузки». Для LLM общий
   загрузчик Ollama может продолжать работу другого клиента. Для ASR
   возобновление зависит от доступности сохранённой части и версии источника.
