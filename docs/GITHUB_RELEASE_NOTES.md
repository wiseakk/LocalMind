# LocalMind Linux Alpha · 1.0.0rc3-4

Кандидат на первый релиз. Целевой тег `v1.0.0-rc3.4-linux-alpha` для исходников приложения в `5ffcc3b`. Архив проверен локально и ожидает разрешения на распространение. Windows RC3 остаётся отдельной линией исходников.

- CachyOS / Arch x86_64 с Python 3.14. Основная графическая приёмка проведена на CachyOS/Hyprland.
- Повторный запуск исправляет конфликт при TCP TIME_WAIT. Диагностика различает ошибку backend, Qt и занятый порт.
- Ollama, модели и голосовые веса подготавливаются отдельно. При нехватке GPU-памяти для голоса используйте CPU-профиль.
- Linux QA проверила 20/20 циклов запуска извлечённого пакета под Wayland. Windows-микрофон и GPU в этом цикле не проверялись.
