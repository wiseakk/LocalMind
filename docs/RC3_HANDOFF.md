## Запуск и offline demo

После подготовки зависимостей по README запуск Qt с сервером одной командой:

```powershell
.\.venv\Scripts\python.exe -m localmind.desktop
```

Сервер без оболочки: `.\.venv\Scripts\python.exe -B start.py`, затем
`http://127.0.0.1:8765`. Это не проверка Qt или системного трея.
После успешной сборки распакованное приложение запускается командой
`.\dist\rc3\LocalMind\LocalMind.exe`; установленное — ярлыком LocalMind.

Для offline demo заранее явно подготовить Small либо Medium, Silero xenia и
локальную LLM в Ollama. Загрузка требует сети; inference локальный. Завершить
мастер (голос можно явно отложить), пройти или пропустить мини-тур. Затем
отключить сеть: задать вопрос про RSA/пельмени, проверить три беседы, отрицания

Блокнота проверять отдельно с подтверждённым доступом. Не сохранять аудио без
согласия. Offline demo физически в этой сессии не проведено.

## Что исправлено

- Ввод фиксируется до stream и действий; только commit пары сообщений поглощает
  совпадающий черновик. Обрыв до final не создаёт завершённого ответа.
- Pagehide во время stream не ставит пустой autosave за блокировкой хода.
- SQLite повторно проверяет версию схемы после получения транзакционной блокировки.
- Найденная, ещё не проверенная Medium выбирается без ненужной загрузки Small.
- DOM/Playwright fixtures приведены к мастеру RC3 и единому окну настроек;
  добавлены проверки перезапуска процесса, аварии, onboarding/тура и OS-lock.

TTL/capacity относятся к оперативному кешу, а не к постоянному журналу. Чтение
бесед не возвращает временные file/window tokens, grants или кнопки выполнения.
Автоматический повтор использует прежний request_id только в прежнем server_instance.
После аварии результат уже начавшегося действия надо проверить вручную перед
явной новой отправкой. Exactly-once через аварийный выход не заявляется.

## Troubleshooting

- Ошибка истории/диска: сохранить доступный текст из поля, освободить место,
  проверить доступ к каталогу данных. База `history/conversations.sqlite3`;
  не удалять её для ремонта. Для копирования полностью выйти из приложения.
- Обрыв stream: в исходном сервере повторить тот же запрос безопасным UI-повтором;
  после перезапуска проверить действие вручную. Открытие беседы ничего не выполняет.
- `unverified`: файлы найдены, но нужна проверка модели; это не повод скачивать
  Small поверх установленной Medium. `dependency_missing`: восстановить установку.
- Прерванная загрузка: нажать «Повторить» отдельно для ресурса. Проверенный prefix
  возобновляется по Range; неверный hash не публикуется. Не удалять модели/backup.
- Мастер не сохраняется: проверить диск и права; ошибка должна остаться видимой.
  Повтор мастера/тура: Настройки → Дополнительно. Пропажа моделей не сбрасывает completion.
- 422 STT: проверить размер, формат и длительность; исправить transcript вручную.
  Нет CUDA: проверить CPU fallback, не устанавливать драйверы автоматически.
- Занят порт: штатно закрыть прежний LocalMind; не завершать все Python/Ollama.
  При GUI recovery восстановить установку, не отключать Chromium sandbox.
