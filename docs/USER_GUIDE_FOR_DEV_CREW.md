# Как пользователь контролирует DevCrew, чтобы понимать проект на защите

После каждой milestone попроси DevCrew ответить в `docs/TEACHBACK.md` простым языком:
1. Какие файлы изменены и что отвечает за каждую часть.
2. Как проходит одно голосовое сообщение по всей цепочке.
3. Где LLM принимает решение, где программа проверяет и выполняет действие.
4. Что сделать, если разбирает «пельмени» неправильно; как доказать улучшение на аудиозаписях.
5. Почему нельзя запускать `subprocess` с текстом из LLM; как работает каталог приложений.
6. Как проверить всё вручную за 3 минуты.
7. Пять вероятных вопросов экспертов с ответами в 3–5 предложениях.

Пусть второй участник выполняет настоящий вклад: записывает пользовательские тесты/обнаруживает UX-проблемы, помогает организовать эксперимент и готовит презентацию/демонстрацию. Не приписывать сделанную ИИ разработку человеку, который её не проверял.
