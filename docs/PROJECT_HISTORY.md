Linux `port/linux-arch` и Windows `release/1.0.0-rc3` имеют общую историю. В Windows-копии RC3 активна отдельная ветка `codex/rc3-semantic-intents`, доступная в Linux как `origin/codex/rc3-semantic-intents`. Тег `rc3-pre-ui-final` сохраняет раннее состояние интерфейса. Ранний Windows-репозиторий MVP содержит дополнительные рабочие ветки и резервные refs. Его коммит `66f6c10` входит в историю Linux.

```sh
git log --graph --oneline --decorate --all
git merge-base port/linux-arch release/1.0.0-rc3
git show --stat 5ffcc3b
```
