# Сборки LocalMind

## Arch / CachyOS x86_64

Пакет rc3-5 устанавливает код, launcher, desktop entry, иконку и лицензионные
уведомления. Python, Qt WebEngine и остальные системные зависимости получаются
из репозиториев Arch/CachyOS при установке. Модели и голосовой runtime
подготавливаются отдельно. Это уменьшает пакет и позволяет обновлять
системные библиотеки средствами пакетного менеджера.

Для локальной сборки из чистого checkout на совместимой версии Arch нужны
`base-devel` и зависимости `PKGBUILD`. Команда `makepkg -si` собирает и устанавливает
пакет. Для установки проверенного файла используйте
`sudo pacman -U ./localmind-1.0.0rc3-5-x86_64.pkg.tar.zst` и запустите `localmind`.
Для чистой приёмки см. [ручную проверку](QUICK_DEMO.md).

GitHub Actions дважды собирает один коммит с одинаковой датой сборки в
одном Arch-окружении и сравнивает архивы. Затем проверяет, что все файлы
совпадают с checkout, выполняет установку через pacman и проверяет импорты
Qt и локальный HTTP. Пакет из другого состояния rolling-дистрибутива может
отличаться. Подлинность исторического rc3-4 и его bundled runtime проверяется
отдельно.

## Windows 10/11 x64

`scripts/build_windows.py` требует Windows, Python 3.11 x64, Inno Setup и
компилятор .NET Framework. Он готовит встроенные Python, Qt и Ollama, а
Inno Setup создаёт EXE, ярлыки, иконку и деинсталлятор для текущего пользователя.
Без параметров offline assets модели подготавливаются в онбординге.

Ручной Windows workflow проверяет сборку, тихую установку, импорты из
встроенного Python и деинсталляцию. Он оставляет установщик внутри runner.
Перед публичной загрузкой нужны проверка условий распространения Qt/Chromium,
Ollama и вложенных wheel, а также приёмка чистой Windows с окном, GPU и
микрофоном. [Лицензии](LICENSING.md) · [Чек-лист Windows](../MANUAL_QA.md)

AppImage отложен до проверки совместимости Qt WebEngine и его песочницы
на дополнительных дистрибутивах.
