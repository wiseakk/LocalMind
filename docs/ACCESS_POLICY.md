# Возможности LocalMind — RC3

Функция реализована в исходниках. Полная ручная приёмка Windows остаётся
открытой: автоматические тесты и подменённые приложения её не заменяют.

## Запуск и offline demo

Из подготовленного окружения проекта:

```powershell
.\.venv\Scripts\python.exe -m localmind.desktop
```

До отключения сети подготовьте локальные LLM, Whisper small/medium и Silero
через существующий мастер ресурсов. Это разовые загрузки; правила доступа
разбираются детерминированно и не используют LLM или сеть. После отключения
сети: вопрос про RSA, исправление расшифровки, разрешённый Блокнот, поиск
тестового PDF, запрет папки и отказ при повторном поиске, DEMO-лампа.
Используйте только специально созданные тестовые файлы. Настоящий
offline/STT/TTS/GPU прогон в этой работе не подтверждён.

## Backend и сохранение

Единая политика `private/personal_mode.json` содержит версию схемы 2, SID,
режим, идентичности корней, операции, приложения и явные правила. Сохранение
атомарное, с flush/fsync и заменой файла; история и `product-state.json`
полномочий не содержат. Чужой SID, неизвестная схема, повреждение или подмена
корня закрывают доступ. Ошибка сохранения возвращает прежние права.
Отдельный сбой записи журнала отображается предупреждением и не меняет факт
успешно сохранённой политики.

Приоритет: обязательные исключения → пользовательские запреты → разрешения
области/операции/режима. Неизвестная операция запрещена. Полный режим
включается только явным новым выбором. Оба старых режима мигрируют в
ограниченный; старый endpoint полного режима не включает. Сессионные
PDF/source grants, выбранные цели и подтверждения после перезапуска не
восстанавливаются. Любое изменение политики инвалидирует их. Постоянные app
grants привязаны к проверенной цели и fingerprint.

Ограниченный режим использует явно заданные папки и операции. Запуск, фокус
и закрытие приложений разрешаются отдельно. Прежние фиксированные Блокнот и
Калькулятор сохраняются как проверяемые встроенные приложения; одноимённый
произвольный executable таким приложением не становится. Поиск без чтения
возвращает метаданные без чтения байтов и без SHA256.

Полный режим использует профиль и Known Folders текущего токена Windows,
включая перенесённые на другой фиксированный диск. Весь диск не разрешается.
Дополнительные области принимаются только внутри уже проверенных областей;
независимая проверка владения произвольной дополнительной папкой не предлагается.
Чужие профили исключаются также по Windows ProfileList, независимо от диска.
Секреты, ключи, хранилища браузеров, системные области, код/runtime/настройки
LocalMind остаются закрыты.

Документы с symlink/reparse/junction или несколькими жёсткими ссылками
отклоняются. Сохраняются handle-based блокировки файлов и родителей против
замены. Для перемещения проверяются оба конца. Каждое изменение файла
требует точного одноразового подтверждения; пакетного исполнителя нет.

Программы запускаются из проверенного каталога с `shell=False`. Документ и
фиксированная закладка открываются через разрешённое проверенное приложение
с фиксированным argv; command-template ассоциации не исполняется.
У штатных Windows executables могут быть hardlinks: запреты сравнивают также
identity образа. Терминала, административных прав, произвольных аргументов
или автоматического ввода в приложения модель не получает. Запуск приложения
**не создаёт OS sandbox**: пользователь затем сам работает в нём с правами
Windows. Автоматическое закрытие разрешено только проверенному Калькулятору;
документные приложения защищены от потери несохранённых данных.

## Русские правила

Введите одно правило → «Показать интерпретацию» → при необходимости уточните
область → «Применить правило» или отмените. Черновик ничего не меняет.
Поддержаны три формы из задания: запрет папки целиком; запуск приложения с
запретом закрытия; редактирование документов с запретом удаления.
Неизвестное приложение, неоднозначная область, неподдерживаемая составная
фраза и противоречие пересекающихся правил требуют уточнения целиком.
Allow приложения привязан к образу, deny действует на все его IDs/aliases.
Для изменения противоречащего правила сначала удалите его отдельной кнопкой.

## Ручной чек-лист Windows — только на тестовых данных

Записывайте дату, ОС, commit/worktree, скриншоты и реальные результаты каждого
пункта. Исторические отчёты новой приёмкой не являются.

- [ ] Оба режима, клавиатура, явное сохранение полного режима.
- [ ] Разрешённый файл читается; запрещённый файл и вложенные пути — нет.
- [ ] Поиск без чтения показывает только метаданные; операции создания,
  перезаписи, перемещения и удаления выключаются независимо.
- [ ] Три русских примера: preview инертен, apply действует, отмена инертна;
  неизвестное имя/область уточняются без частичного применения.
- [ ] Parent deny перекрывает дочерние allow и точный PDF grant;
  противоречие обоих направлений требует уточнения.
- [ ] Obsidian: запуск разрешён, закрытие запрещено через каталог, aliases,
  дубли, прямой API, workspace и ранее выбранное окно.
- [ ] Несохранённый Блокнот не закрывается; редактор с именем calc.exe
  не приобретает право безопасного закрытия.
- [ ] Запрещённое приложение нельзя вызвать через ассоциацию документа или
  браузера. Ярлыки со скриптами, аргументами, cmd/PowerShell отклонены.
- [ ] Symlink, junction/reparse и hardlink: чтение/открытие/изменение отказаны;
  исходный тестовый файл не меняется.
- [ ] Замена файла/родителя после preview/prepare, изменение источника или
  назначения перемещения: старое подтверждение отказано, новые байты не записаны.
- [ ] `..`, относительные, drive-relative, UNC/device, ADS, регистр, 8.3,
  завершающие точки/пробелы. Не включать 8.3 глобально ради теста.
- [ ] Перенесённая Known Folder другого фиксированного диска работает;
  произвольная папка/диск, съёмные и сетевые области запрещены.
- [ ] Чужой профиль и секреты проверяются пустыми фикстурами/подменами;
  настоящие чужие документы, пароли и ключи не открываются.
- [ ] Полный выход процесса и новый запуск: режим/правила/постоянные grants
  восстановлены, сессионные цели и подтверждения не восстановлены.
- [ ] Обе старые политики мигрируют в restricted без расширения; сохранение
  экрана не добавляет операций legacy read-only области.
- [ ] Чужой SID/неизвестная версия/испорченный JSON закрывают доступ;
  ошибка записи не показывается как успешное применение.
- [ ] Журнал содержит причину, правило, ревизию, прямые API и отменённые/
  истёкшие подтверждения; текст документов отсутствует.
- [ ] UI 100/125/140%, клавиатура, Escape/возврат фокуса, reduced motion.
- [ ] Чат/SQLite история/вложения/PDF/каталог/workspaces/закладки/настройки/
  DEMO/HA (только настроенный тестовый HA) не регрессировали.
- [ ] Отдельно проверены микрофон, GPU, CPU fallback, слышимый TTS и offline
  после загрузки ресурсов. Без фактического прогона готовность не заявлять.

## Troubleshooting

- Отказ области: проверьте режим, операции и deny в журнале. Подтверждение
  изменения не отменяет запрет.
- «Политика изменилась»: обновите экран, повторите поиск, preview и подтверждение.
- «Нужна область»: выберите сохранённую папку документов и повторите preview.
- Документ не открывается: обновите каталог и разрешите приложение ассоциации;
  скриптовая/неизвестная ассоциация не запускается.
- Повреждена политика: сохраните резервную копию и заново задайте ограниченные
  права. Не исправляйте проблему включением полного режима.
- Ошибка диска: прежняя политика сохраняется; при отдельном audit_warning
  смотрите фактический режим в ответе и восстановите запись журнала.
- `spawn EPERM`, Chromium pipe `Access is denied (0x5)` или отсутствие browser
  host блокируют UI-проверку. Не отключайте sandbox/ACL/защиту ради демонстрации.

Более 60 вопросов к защите с объяснениями: [DEFENSE_QA.md](DEFENSE_QA.md).
Студент может демонстрировать парсер, приоритет deny, подтверждения, SID и
тесты, не переписывая и не переобъясняя внутренности GUI/LLM/голоса.
