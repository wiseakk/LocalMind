# Скриншоты LocalMind

Снимки сделаны в Chromium на Linux при масштабе 100%, 1440 × 1000, через настоящий FastAPI из `5ffcc3b`. Использован отдельный локальный профиль без пользовательской истории. Внешние запросы Chromium блокировались, а локальный Ollama ответил на демонстрационный вопрос. Голосовые ресурсы в этом профиле не готовились.

[Главный экран](home.png) · [Диалог](chat.png) · [Голос](voice.png) · [Приложения](apps.png) · [Разрешения](permissions.png) · [Модели](models.png)

Для экрана приложений каталог XDG ограничен копией установленной desktop-записи Калькулятора. LocalMind считал её штатным адаптером. Путь к тестовой папке на снимке относится к временному каталогу.
