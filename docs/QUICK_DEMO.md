# Ручная проверка LocalMind

Используйте пробную папку с одним файлом `demo.txt` и отдельный профиль.
Подготовьте локальную модель, Whisper и Silero. На Linux запустите
`localmind`, если пакет установлен, или
`QT_QPA_PLATFORM=wayland .venv/bin/python -m localmind.desktop` из исходников.

| Действие | Ожидаемый результат | Признак бага |
| --- | --- | --- |
| Открыть окно и спросить «Что такое алгоритм?» | Ответ появляется в беседе, модель выбрана в настройках. | Пустой ответ или зависание без объяснения. |
| Записать фразу и исправить одно слово | Расшифровка остаётся редактируемой до отправки. | Запрос или системное действие выполняется до отправки. |
| Включить озвучку ответа и нажать остановку | Silero проигрывает ответ, кнопка останавливает звук. | Озвучка продолжается после остановки. |
| Разрешить запуск установленного приложения; попросить открыть его; затем написать «Не открывай его» | Первый запрос показывает наблюдаемый результат. Второй не запускает новое окно. | Запуск без разрешения или после отрицания. |
| Разрешить чтение пробной папки и попросить прочитать `demo.txt`. Отозвать доступ и повторить. | Сначала виден фактический текст, затем отказ. | Прочитан другой файл или доступ сохранился после отзыва. |
| Запросить удаление пробного файла и отменить | Интерфейс требует отдельное подтверждение, файл остаётся. | Файл исчез до подтверждения или после отмены. |
| После подготовки ресурсов отключить внешнюю сеть и перезапустить Desktop | При доступном loopback прежняя беседа открывается и модель отвечает. | Пропала история, внешний запрос требуется для ответа или порт остаётся занят. |
