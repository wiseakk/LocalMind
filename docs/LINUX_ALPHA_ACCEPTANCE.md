# LocalMind Linux Alpha — финальная приёмка

**Вердикт: LINUX ALPHA BLOCKED.** Системная установка ожидает sudo-аутентификацию,
а системный Ollama на стандартном адресе пока не видит Gemma. Извлечённый
пакет и подготовленные ресурсы прошли проверки без системной установки.

## Обычная машина и модели

- Системный `ollama.service` активен и работает от `ollama`. Ответ
  `http://127.0.0.1:11434/api/version` — **0.40.16**. Установленные пакеты
  `ollama` и `ollama-cuda` — **0.40.16-2.1**.
- Эффективный `OLLAMA_MODELS` системного сервиса — `/var/lib/ollama`.
  Его `/api/tags` вернул `{"models":[]}`. Конфигурация systemd и это хранилище
  не менялись.
- Официальная `gemma4:12b-it-q4_K_M` находится в
  `.test-artifacts/linux-ollama` внутри checkout. Манифест в
  `manifests/registry.ollama.ai/library/gemma4/12b-it-q4_K_M`,
  основной blob `blobs/sha256-bb722270d54346adc198f213851dbe0207e87c3ecf2a0aff4d92262726215391`
  занимает 7 381 383 680 байт. Digest модели в Ollama —
  `6114515d63c17436a7c0417d82820ac65ad643e2806c5a3c89cb62846436ed0b`.
- В отдельном сетевом namespace с одним loopback Ollama на `11434`
  использовал этот каталог и ответил через LocalMind без повторной загрузки.
  Для запуска на обычной машине можно оставить работающий системный сервис
  и использовать отдельный пользовательский daemon на `18766`, как ниже.
- Без `LOCALMIND_DATA_DIR` обычный профиль разрешается в
  `~/.local/share/LocalMind`. Временный `XDG_DATA_HOME` проверен реальной
  записью темы и истории, перезапуском и повторным чтением. Существующий
  пользовательский профиль сохранён.

## Артефакт и сценарии

- Исторический исходник до исправления — `a3fdefff0a96539a7e85e2ad2b81a561336adce1`,
  архив `1.0.0rc3-1`. В чистом профиле подключённый пустой Ollama
  ошибочно переводил точную DEMO-команду в отказ проверки плана.
  Отсутствие локальной модели теперь направляет точную команду в существующий
  детерминированный обработчик. Некорректный ответ модели по-прежнему отклоняется.
- Новый архив — `.test-artifacts/package-final/localmind-1.0.0rc3-2-x86_64.pkg.tar.zst`.
  Git SHA исходников payload — `3e803fa450d6a0a25b9a85dc51117b8530211b4c`.
  SHA-256 `d66dcaf28e3e905a4fd6657e7445e2af6fcf25ed641b2c4e18cec3544df86759`.
  Пакет локальный, неподписанный. Установочных скриптов нет. Payload
  содержит приложение под `/usr/lib/localmind`, launcher `/usr/bin/localmind`,
  desktop entry и PNG под `/usr/share`. Профилей, секретов и весов в нём нет.
- `pacman -Qip`, список файлов и `desktop-file-validate` прошли.
  Системно отсутствуют `python-fastapi`, `uvicorn`, `python-httpx`,
  `python-dotenv`, `python-python-multipart`, `python-pypdf`, `python-pillow`,
  `python-nvidia-ml-py`, `pyside6` и `qt6-webengine`. Их разрешает pacman
  при установке. Проверка `sudo -n -l` потребовала пароль.
- Извлечённый payload запускался с проверенным Python 3.14.10 и зависимостями
  из проектного venv. Проверены Qt WebEngine под Wayland с системным Ollama,
  генерация Gemma на стандартном адресе в namespace, отказ и успешное чтение
  файла после выдачи разрешения, штатная остановка и повторный старт.
  Приёмка через штатный `/usr/bin/localmind` и desktop entry требует установки.
  Установка, обновление и удаление через pacman ещё не выполнены.
- При смене извлечённого payload с `-1` на `-2` тема и беседа сохранились
  в общем XDG-профиле. Python: **1735 passed, 31 skipped, 35 subtests passed**.
  Linux-specific набор: **13 passed**. Chromium против извлечённого `-2`
  с обычным пустым Ollama: **37 passed**. DOM, JavaScript и 86 ассетов прошли.

## VRAM и голос

При резидентной Gemma `ollama ps` показал **100% GPU**, контекст 4096. Перед
запуском Medium было **1432 МиБ** свободной VRAM. Medium вернул
«Как работает RSA?» на **CPU/int8_float32**, `fallback=true`, за **1646 мс**
inference. После fallback ASR-процесс всё ещё удерживал около 1370 МиБ
GPU-памяти, свободными оставались 64 МиБ. После его выхода VRAM вернулась к
исходному уровню и Gemma выполнила следующий запрос. Для последовательного
демо с уже резидентной Gemma используйте Small / CPU. Физический микрофон и
слышимость требуют ручной проверки.

## Команды установки и приёмки

Из корня checkout, на обычной системе:

```sh
sudo pacman -U .test-artifacts/package-final/localmind-1.0.0rc3-2-x86_64.pkg.tar.zst
pacman -Q localmind
gtk-launch localmind
```

Для обновления на новую локальную сборку используйте
`sudo pacman -U /путь/к/новому/localmind-ВЕРСИЯ-x86_64.pkg.tar.zst`.
Перед удалением штатно закройте Desktop, затем выполните `sudo pacman -R localmind`.
Пакет владеет только файлами приложения под `/usr`. При ручной проверке
сохранности повторно запустите приложение после переустановки и откройте
прежнюю беседу. Для установки голосовых зависимостей см.
[руководство](LINUX_INSTALL.md#arch-пакет-из-checkout).

Для проверки с уже скачанной Gemma без изменения системного сервиса
запустите из корня checkout в отдельном терминале:

```sh
env HOME="$PWD/.test-artifacts/linux-offline-home" OLLAMA_HOST=127.0.0.1:18766 \
  OLLAMA_MODELS="$PWD/.test-artifacts/linux-ollama" OLLAMA_NO_CLOUD=1 OLLAMA_NOPRUNE=1 ollama serve
```

Одна команда запуска установленного Desktop с обычным XDG-профилем:

```sh
env -u LOCALMIND_DATA_DIR OLLAMA_URL=http://127.0.0.1:18766 localmind
```

1. Запустите из меню и проверьте подключение к штатному Ollama. С выбранной
   подготовленной Gemma спросите «Как работает RSA?». Ожидается ответ про
   открытый и закрытый ключи, с указанием локальной модели в диагностике.
2. Дайте отдельное разрешение Kitty и тестовой папке. Напишите «Открой Kitty»
   и «Прочитай файл „/абсолютный/путь/файл.txt“». Проверьте окно и точный текст.
   Отзовите разрешение чтения. Повтор должен завершиться отказом.
3. В разделе «Голос» выберите физический микрофон. Нажмите запись, скажите
   «Как работает RSA?», остановите запись. Проверьте редактируемую расшифровку,
   отправьте её, прослушайте Silero, затем нажмите «Остановить озвучку».
   Повторите с отключённым внешним соединением и доступным loopback.
4. Закройте Desktop, перезапустите. Проверьте историю, тему и разрешения.
   Повторите после обновления пакета и после удаления с переустановкой.
   Не удаляйте каталог профиля и модели.
