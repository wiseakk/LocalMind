# Как работает LocalMind — объяснение без магии

## Ты сказал «включи настольную лампу». Что происходит?

1. Микрофон получает **аудиосигнал** — последовательность звуковых отсчётов. Никакой «магии понимания» ещё нет.
2. **STT** (speech-to-text) превращает аудио в строку «Включи настольную лампу». В опциональной сборке используется faster-whisper. Фактически вычисляет ПК. Распознанный текст только помещается в редактируемое поле и сам ничего не запускает.
3. Пользователь проверяет или исправляет текст и явно нажимает «Отправить». Сервер FastAPI получает текст в `/api/chat`, проверяет ключ, размер сообщения и признак авторизации действий.
4. **Маршрутизатор** (`assess_action` в `agent.py`) отклоняет отрицания, цитаты, вопросы, смешанные и неоднозначные формулировки. Для одной ясной команды он фиксирует точное действие и цель; LLM для выбора действия не используется.
5. **Шлюз** (`set_light` в `devices.py`) сверяет `desk_light` со списком разрешённых устройств и действие с `on`/`off`.
6. Если `DEMO_MODE=true`, обновляется переменная состояния `_demo_states`. Это **только симуляция**.
7. Если `DEMO_MODE=false`, Home Assistant получает POST `/api/services/light/turn_on` с `entity_id` лампы. От Home Assistant зависит доставка команды реальному устройству.
8. Сервер отдаёт JSON с `answer`, `engine`, `actions` и `latency_ms`; интерфейс отображает результат и журнал.

## А если спросить «Почему небо голубое?»

Быстрый маршрутизатор не видит конкретной разрешённой команды. Тогда `agent.py` собирает список сообщений, добавляет инструкцию и посылает запрос Ollama на `POST /api/chat`.

Ollama запускает модель **на компьютере**, модель формирует только текстовый ответ. Исполняемые инструменты модели не передаются: все поддерживаемые действия до обращения к Ollama разбирает серверный маршрутизатор.

## Какие здесь библиотеки?

- **FastAPI**: веб-сервер, маршруты `/api/...`, проверка формата входных данных.
- **Ollama**: готовый runtime для запуска LLM, предоставляет стандартный локальный API.
- **faster-whisper**: готовая система STT, устанавливается отдельно.
- **Home Assistant**: программа управления устройствами — не нейросеть и не Matter сама по себе.
- **Piper**: предлагаемый следующий этап для полностью локальной озвучки; **не входит** в MVP 0.1.

## Почему нельзя просто просить нейросеть вызвать CMD?

LLM иногда неправильно понимает запрос или может подчиниться вредной инструкции. Поэтому в этой версии модель вообще не выбирает исполняемое действие. Сервер сам выделяет только одну разрешённую операцию, повторно сверяет точное имя и параметры в `dispatch`, а неизвестные команды отклоняет. Это называется **граница доверия**.

## Что измерить, чтобы проект был исследованием?

Одинаковые 20–50 запросов выполнить в двух режимах: через быстрые правила (там, где они подходят) и через LLM (отключив fast path в исследовательской ветке). Проверить долю правильных действий, медианную задержку и 95-й перцентиль. Затем объяснить: какой путь лучше, когда и почему. Не выдумывать данные.
