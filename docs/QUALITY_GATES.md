# Quality Gates — обязательные проверки до передачи пользователю

Не считать продукт готовым из-за простого `200 OK`: это говорит только, что HTTP обработал запрос.

## G0: baseline
- `python -m pytest -q` проходит; старый интерфейс/свет/чат не ухудшены.
- Указаны реальные версии Python, PyAV, faster-whisper, CTranslate2, Ollama; PyAV совместим с декодированием WebM.
- Нет секретов в Git; нет небезопасных дефолтных LAN listeners.

## G1: STT
- Пользователь может видеть и исправлять распознанную фразу ПЕРЕД действием.
- Ошибки декодирования, пустая запись, шум без речи, неправильный формат и слишком длинное аудио обработаны корректно.
- Реальные записи в `docs/STT_TEST_SET.csv` — только если получены и по согласию. Без аудио: test plan готов, итог accuracy НЕ УСТАНОВЛЕН.
- Сравнивать модели на ОДНИХ и тех же записях; сохранять raw transcript, WER/CER, latency, hardware и настройки с приватностью.

## G2: Desktop app discovery
- На Windows каталог выводит доступные программы (если есть) из Start Menu / рабочего стола, более 2 захардкоженных названий.
- Пропущенные/поломанные .lnk не ломают каталог.
- Неизвестное имя не запускает ничего; похожие имена требуют выбора.
- Не допускается запуск `cmd`, powershell, URL или произвольной команды из ответа LLM; команда с shell metacharacters не меняет путь/аргументы.
- Пояснение/отрицание/цитата команды не запускают приложение.
- «Закрой» не может потерять документ и не убивает посторонние процессы.

## G3: LLM + TTS
- RSA, пельмени, школьная тема не требуют интернета после локальной установки модели.
- Голосовой ответ воспроизводится локально или корректно сообщает о ненастроенном голосе.
- Не скрывает фактические ошибки инструмента за "готово".
- При пропущенном инструменте, отсутствующей модели и таймауте UI не зависает.

## G4: UI + безопасности
- На 100% и 140% масштабах доступна кнопка записи, raw transcript, коррекция, история действий.
- Состояние DEMO/REAL невозможно перепутать.
- Микрофон не пишет постоянно без согласия; сеть и приватность описаны точно.
- В LAN — сопряжение + защищённый канал или функция явно недоступна.

## G5: доказательства
- Команды запуска на Windows, инструкции дебага и cleanup.
- Полные автоматические результаты и явные пункты "Не тестировалось".
- Реальные скрины/видео только с работающей сборки; никакого fake benchmark.
- 30+ вопросов для жюри с объяснением откуда что берётся.
