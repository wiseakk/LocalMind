Приложения и доступ
Каталог обнаружен автоматически. Разрешения запуска, фокуса и закрытия проверяет контроллер доступа. Изменённая цель требует повторной проверки. Закрытие допускается только с защитой несохранённых данных.
Блокнот и Калькулятор проверяются отдельно по системному пути. Для неоднозначного имени выберите точное название.
