# Ограничения кандидата 1.0.0-rc1

- Нет release-коммита, тега кандидата, Setup.exe, release Source.zip и их SHA256.
  Git index вне workspace недоступен, Inno Setup отсутствует. Скрипт сборки
  останавливается на preflight до сетевых загрузок. Alpha и все worktree сохранены.
- Чистая Windows без Python/Node, установка/обновление/удаление, установленный EXE
  и сопоставление Python/EXE: NOT TESTED. Нельзя называть сборку Stable.
- Реальный микрофон, качество начала фразы/отрицаний, десять голосовых запросов,
  Silero xenia, STT CPU fallback и RTX 4070: NOT TESTED в текущей интеграции.
  Unit-тесты и диагностические моки не заменяют эти проверки.
- Playwright не создал worker (`spawn EPERM`); browser access host CUA недоступен.
  Визуальный UI и браузерная ручная матрица: NOT TESTED; DOM-тесты выполнены отдельно.
- `ministral-3:8b` не установлена; сравнение на одинаковых запросах: NOT TESTED.
  Локальная gemma4 прошла только один RSA text smoke. Это не оценка точности фактов.
- Windows может запретить foreground activation; запуск сохраняется успешным,
  предлагается выбрать окно через панель задач. В реальном Python smoke окна
  обнаружены, activation_denied. Непроверенное безопасное закрытие Notepad отказано;
  созданный пустой Блокнот оставлен открытым для ручного закрытия.
- Реальные байты сетевой загрузки, отмена и повтор: NOT TESTED в этой интеграции.
  При разрыве pull клиент не может доказать прекращение работы общего Ollama.
- Перед копированием моделей общего Ollama завершите задачи всех его клиентов.
  LocalMind проверяет хеши до/после, сохраняет источник и не останавливает чужой daemon;
  он не может запретить внешнему процессу запись в исходный каталог.
- После смены каталога требуется перезапуск. История обычного браузера остаётся
  в профиле этого браузера; desktop использует webprofile в каталоге LocalMind.
  При отказе переноса старые файлы сохраняются; импорт не считается выполненным.
- Разрешения и HA-секреты не переносятся автоматически вместе с legacy preferences.
  Удаление приложения сохраняет данные; удаление данных требует отдельного согласия.

Troubleshooting и протокол: `MANUAL_QA.md`. Вопросы для защиты с пояснениями:
`docs/DEFENSE_QA.md` (30+ вопросов).
