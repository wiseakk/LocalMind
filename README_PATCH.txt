LocalMind голосовой диагностический патч 0.1.1

1. Останови сервер Ctrl+C.
2. Распакуй архив поверх папки LocalMind_MVP_01 (заменив localmind/server.py и static/index.html).
3. Запусти: .\.venv\Scripts\python.exe start.py
4. Обнови браузер Ctrl+F5.
5. Нажми микрофон, говори 3-5 секунд, нажми квадрат для завершения.
6. Если снова 422, скопируй из PowerShell строки после STT ERROR и traceback (без секретов и токенов).

Патч не гарантирует исправления конкретной причины распознавания; он раскрывает её для диагностики.
