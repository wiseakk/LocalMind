# Как внести вклад

Используйте отдельную ветку и небольшой коммит с причиной изменения. Укажите ОС, версию Python и команды проверки. Запустите `python -m pytest -q` и проверки UI из [протоколе проверок](docs/DEVELOPMENT_EVIDENCE.md#воспроизведение).

Для изменений системных действий объясните, какие цель и разрешение проверяются и как код отличает подтверждённый результат от попытки. Используйте временный профиль, демонстрационные данные и заглушки для CI. Для ручных интеграций укажите модель, оборудование и условия.

Перед приложением скриншота, лога или SQL-дампа проверьте его на личные данные. При обнаружении уязвимости следуйте [SECURITY.md](SECURITY.md).
