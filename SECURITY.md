# Безопасность LocalMind

Поддерживаемая линия разработки — Linux Alpha и Windows RC3. API рассчитан на loopback. Меняйте правила доступа из интерфейса и оставляйте DEMO для экспериментов с устройствами.

Для сообщения об уязвимости используйте приватный канал GitHub Security, когда он включён, или свяжитесь с владельцем репозитория напрямую. Укажите коммит, платформу, ожидаемое и наблюдаемое поведение. Открытые issues подходят для обычных ошибок. Храните ключи, личные пути и содержимое диалогов в локальном профиле.
