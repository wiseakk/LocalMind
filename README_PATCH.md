# LocalMind 0.1.2 — патч логики диалога и управления ПК

**Назначение:** установка поверх LocalMind 0.1.1, где уже работает распознавание голоса.

1. Закрой локальный сервер (`Ctrl+C`).
2. Распакуй содержимое данного ZIP в корень папки `LocalMind_MVP_01` — туда, где находятся `start.py` и папка `localmind`, **с заменой файлов**.
3. Ничего в `.env`, `.venv` и `config/devices.json` заменять не требуется — этих файлов в патче нет.
4. Перезапусти сервер:
   ```powershell
   .\.venv\Scripts\python.exe start.py
   ```
5. Открой `http://127.0.0.1:8765`, сделай `Ctrl+F5`.

## Что изменено

- Обновлён системный промпт. Отсутствие интернета не является основанием отказываться объяснять общие сведения.
- Для обычных вопросов модель вызывается БЕЗ набора инструментов. Они передаются только при запросе, похожем на реальное действие.
- Команды «запусти калькулятор/блокнот» работают по детерминированному правилу, без ожидания LLM.
- Команда «закрой калькулятор»: только Windows, только после запуска через LocalMind в текущей сессии. Используется фиксированное имя `CalculatorApp.exe` (без произвольных команд). ЗАКРЫВАЮТСЯ ВСЕ ОКНА калькулятора. На некоторых версиях Windows процесс может называться иначе — в этом случае LocalMind сообщает, что не удалось закрыть приложение.
- Принудительное закрытие блокнота НЕ реализовано: возможна потеря несохранённого текста.
- Вопросы типа «как включить настольную лампу?» больше не исполняются как команда включения.
- В `requirements-voice.txt` зафиксирован PyAV 18.1.0, чтобы избежать повторения несовместимости `metadata_errors`.
- Добавлены 4 теста (всего 9 успешно пройденных тестов без реальной Ollama).

## Проверь голосом

1. «Что такое RSA-шифрование?» — должен объяснять асимметричное шифрование, а не ссылаться на отсутствие интернета.
2. «Как сварить пельмени?» — должен дать рецепт.
3. «Запусти калькулятор» — запускает Calculator; движок `rules`.
4. «Закрой калькулятор» — пытается закрыть CalculatorApp.exe. Не используется для Блокнота.
5. «Расскажи, как включить настольную лампу» — объясняет, НЕ переключает лампу.
6. «Включи настольную лампу» — управляет только демо-лампой, если `DEMO_MODE=true`.

**Проверки в разработческой среде:** 9/9 pytest. Реальный Windows 10, установленный CalculatorApp и ответы Qwen3 по речи пока не тестировались. Если модель всё равно ошибается — возможно, нужна более сильная LLM, другая формулировка запроса или повторное тестирование без предыдущей истории диалога (обнови страницу).
