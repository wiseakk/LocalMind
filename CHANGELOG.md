# Изменения LocalMind

## Linux Alpha · 1.0.0rc3-4

- Исправлен повторный запуск Qt Desktop после закрытия HTTP-соединений в TCP TIME_WAIT.
- Диагностика различает занятой порт, ошибку запуска backend и ошибку Qt.
- Штатное завершение останавливает Uvicorn и освобождает listener.
- Голосовой runtime и проверки загрузок унаследованы от rc3-3.

## Windows RC3

- Онбординг голосовых ресурсов, возобновляемые загрузки и импорт Whisper.
- Локальная история, подтверждение действий, проверка выбора приложения и файлов.
- Отдельная Windows-ветка сохраняет историю до Linux-порта.
