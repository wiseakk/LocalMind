Исходники после подготовки окружения запускаются одной командой `python start.py`.
Установленное приложение: `& "$env:LOCALAPPDATA\Programs\LocalMind\LocalMind.exe"`.
Подготовка source окружения и зависимостей описана в `README.md`; она требует сети.

Перед offline demo через настройки явно подготовить STT выбранного профиля,
Silero xenia и одну локальную LLM. Зафиксировать подтверждение ресурсов, затем
отключить сеть и выполнить шесть фраз. В комплекте `--offline-assets` STT/TTS
копируются из проверенных ресурсов после выбора пользователя; без локальной LLM
одни voice assets не дают полный offline demo. Другие профили необязательны.

Сравнение моделей: установить Ministral только по явному выбору. Для каждой модели
открыть пустые беседы, задать thinking off, temperature 0.2, context 4096,
max tokens 384, keep-alive 300. Использовать одинаковые вопросы: RSA, пельмени,
«Не открывай калькулятор», «Открой блокнот», факт с известным первичным источником.
Записать model digest, фактический Ollama payload (без личной истории), сырой ответ,
выбранное действие и результат адаптера, задержку, /api/ps и RSS/VRAM как наблюдения,
не пиковую память. Синтетический model benchmark не заменяет обычные диалоги.
Default менять только после подтверждённого выигрыша. Чужие задачи не выгружать.

Troubleshooting:

- 422 при записи: проверить размер/длительность/формат, записать ещё раз;
  убедиться, что не отправляется пустой буфер. Не исправлять transcript незаметно.
- 503: открыть диагностику, проверить наличие STT/TTS resources и компонентов.
  Отсутствующие библиотеки в EXE восстанавливаются установщиком, не pip у пользователя.
- Ollama недоступен: запустить установленный Ollama, проверить выбранную модель
  и loopback URL. Не загружать несколько моделей без необходимости.
- Окно не активировано: выбрать его на панели задач. Не повторять запуск
  только из-за foreground error; не использовать taskkill для «исправления».
- Прерывание загрузки: посмотреть реальные completed/total и диагностику,
  дождаться завершения операции Ollama, повторить кнопкой. Проценты не выдумывать.
- Ошибка переноса/недостаток места: источник сохранён; устранить причину,
  сформировать новый план. Не удалять старые ресурсы до проверки нового запуска.
- Сервер занят: завершить предыдущий LocalMind штатно. Не останавливать все Python
  или Ollama процессы. Listener должен быть только 127.0.0.1, proxy headers выключены.
- Сборка: `docs/RELEASE_RECOVERY.md`; менять ACL или системную конфигурацию для
  обхода sandbox не требуется. Релиз собирается вне ограниченной сессии.

Для защиты: `docs/HOW_IT_WORKS.md`, `docs/ARCHITECTURE.md`,
`docs/DEFENSE_QA.md` с 30+ поясняющими ответами. Непроведённые опыты не выдумывать.
