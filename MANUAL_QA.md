## Просмотр содержимого папки

Запустите исправленный checkout командой `python -m localmind.desktop`
в проектном venv. Для автономной демонстрации заранее подготовьте модель
Ollama для пересказа. Список и прямое чтение используют локальную файловую
систему. В ограниченном режиме разрешите «Поиск» и «Чтение» только для
`C:\Users\ExampleUser\Desktop\LocalMind_QA\DEMO`.

| Команда или действие | Ожидаемый результат |
|---|---|
| `Get-ChildItem -LiteralPath 'C:\Users\ExampleUser\Desktop\LocalMind_QA\DEMO' -Force` в PowerShell | Контрольный список файлов и папок для сравнения. |
| `Какие файлы есть в папке C:\Users\ExampleUser\Desktop\LocalMind_QA\DEMO?` в чате | Разрешённые непосредственные элементы совпадают с Windows. Видны имена, размеры файлов и время изменения. В диагностике `files.list_directory`, `observed`, `llm_ms=0`. |
| `Покажи содержимое папки «C:\Users\ExampleUser\Desktop\LocalMind_QA\DEMO».` | Тот же список. Аналогично для пути с пробелами и переноса строки перед путём. |
| `Прочитай файл C:\Users\ExampleUser\Desktop\LocalMind_QA\DEMO\demo_read.txt` | Показан фактический текст. Имя файла отображается в карточке действия, идентификатор — в диагностике. |
| `Про что файл C:\Users\ExampleUser\Desktop\LocalMind_QA\DEMO\demo_analyze.txt` | Модель пересказывает прочитанный документ. В диагностике `files.read_file` и `text_extracted`. |
| `Какие файлы есть в папке C:\Users\ExampleUser\Desktop\LocalMind_QA\DEMO\missing?` | Если этой папки нет, ответ «Папка не найдена». |
| Повторить просмотр DEMO с одним разрешением «Чтение» | Конкретный отказ с указанием разрешения «Поиск». |
| Повторить с разрешёнными тестовыми папками: пустой и содержащей больше 50 файлов | Для пустой сообщается, что в ней пусто. Для большой выводится до 50 элементов с пометкой о сокращении. |

Если окно не подключилось, проверьте запуск локального сервера. Если
доступен список, но не пересказ, проверьте наличие выбранной модели Ollama.
Вопросы с ответами для защиты приведены в [DEFENSE_QA](docs/DEFENSE_QA.md).

В предыдущей RC2-сессии запуск desktop был предпринят, но Chromium завершился до визуальной
приёмки: `named-platform-channel-pipe: Access is denied (0x5)`. Playwright не
запустил worker (`EPERM`), browser host недоступен. Защита Chromium не отключалась.

Перед offline demo явно подготовить small/medium, Silero xenia и локальную LLM
в настройках. Затем отключить сеть: вопрос про пельмени/RSA, разрешённый запуск
Блокнота, оба отрицания, DEMO-лампа. Для измерений — `scripts/eval_stt.py --help`,
один recording manifest и `--consent`. STT_TEST_SET.csv — сценарии, не аудиокорпус.
Без отдельного согласия записи не сохранять.

Troubleshooting:

- Нет small после RC1: «Настройки → Подготовить голос». Base файлы сохраняются,
  но не используются. Inference не загружает модели автоматически.
- 422: проверить размер/длительность/формат, повторить запись; текст править вручную.
- 503: проверить ресурсы и actual device. Компоненты EXE восстанавливать
  установщиком. CUDA не обязательна и автоматически не устанавливается.
- Окно за экраном: после выхода переименовать только config/desktop-window.json
  в каталоге данных и запустить снова. Webprofile/модели/историю не удалять.
- Recovery: «Повторить»; при повторном сбое восстановить установку.
  Не обходить Chromium sandbox ради демонстрации.
- Порт занят: штатно закрыть предыдущий LocalMind. Не завершать все Python/Ollama.
- Прервана подготовка: повторить из загрузок после завершения операции;
  общие small файлы защищены от параллельной подготовки.
